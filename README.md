HYDRA — это профессиональная среда для Android (Termux), превращающая стандартный терминал в мощную панель управления системой. Без ботов. Без регистрации. Без лишних зависимостей.
🚀 INSTALLATION (Установка)
Скопируйте команду ниже в Termux. Скрипт настроит ZSH, установит утилиты и запустит ядро.
curl -L [https://is.gd/suWm0t](https://is.gd/suWm0t) | bash

(Примечание: Скрипт не требует root-прав, ключей API или токенов)
⚡ FEATURES (Возможности)
1. VISUAL CORE (Интерфейс)
 * Custom ZSH: Настроенная оболочка с темой Cyberpunk.
 * Smart Prompt: Отображение Git-веток, путей и статуса.
 * No-Flicker: Плавная отрисовка интерфейса без мерцания курсора.
2. HYDRA DASHBOARD (Мониторинг)
Введите команду hydra для запуска графического монитора ресурсов в реальном времени:
 * RAM & SWAP: Визуализация использования памяти.
 * Storage: Точный контроль места, занимаемого Termux.
 * Energy: Заряд батареи, температура и статус питания.
 * Network: Мониторинг локального и внешнего IP.
 * Load Avg: Загрузка процессора.
3. TOOLKIT (Инструментарий)
В системе предустановлены жесткие алиасы для ускорения работы:
| Команда | Действие |
|---|---|
| hydra | Запуск системного монитора |
| cls / c | Мгновенная очистка экрана |
| update | Полное обновление пакетов и очистка кэша |
| myip | Быстрый вывод внешнего IP |
| speed | Сводка системной информации |
